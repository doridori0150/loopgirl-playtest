작업과 전달

공개 작업실입니다. 수정 후 게임 화면으로 확인하고 수정본 파일을 전달하세요. 브라우저 보관·파일 저장이 공개 게임의 대사나 플레이 저장을 바꾸지는 않습니다.

  1. 왼쪽에서 이벤트를 찾고 장면을 선택합니다.
  2. 대사·선택지 또는 컷신·연출을 편집합니다.
  3. 변경 전후를 확인하고 수정본 보내기를 눌러 파일을 전달합니다.

작업 내용은 이 브라우저에 자동 보관됩니다. 다른 PC로 옮기거나 전달하려면 반드시 수정본 파일을 저장하세요. 브라우저 기록 삭제·비공개 모드에서는 보관 내용이 사라질 수 있습니다.

수정본 열기는 같은 기준 대본의 작업을 합칩니다. 같은 이벤트를 이미 수정했다면 덮어쓰기 여부를 묻습니다. 기준 대본이 다른 파일은 열지 않고 담당자에게 재검토를 요청합니다.

‘이전 화면 유지’는 새 화면을 지정하지 않는다는 뜻이고, ‘해제’는 현재 컷신·초상을 내린다는 뜻입니다.

조건·보상·분기 연결은 참고용입니다. 구조를 바꿔야 하면 해당 장면의 연출 메모에 남기세요. 기준 문장에 연결된 메인 콘티는 대사를 바꿀 때 같이 확인합니다.
