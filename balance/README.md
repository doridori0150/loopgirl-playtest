# 외부 밸런스 편집기

파일 · 변경 이력에서 JSON 내보내기/가져오기를 지원합니다. 저장 버튼도 JSON을 내려받습니다.
현재 수치로 테스트에서 지역·리더·영구 성장을 설정하고 별도 탭에서 실제 게임을 플레이합니다.
테스트 설정의 JSON 불러오기·공개 기본값 복귀·결과 저장을 지원합니다. 테스트 저장은 탭별로 분리됩니다.
수정본은 내려받아 보관하세요. 공개 게임은 별도 적용·검증·배포 후 변경됩니다.
