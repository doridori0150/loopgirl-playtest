# 획득·유물·보급 팩 연구 테스트

팩 개봉 후 OP 리롤, 영구 리롤 횟수·후보 수 연구, 공통 카드 공급·발견, 캠프 지정 보충·원정 덱 교체·타일 강화를 반영했습니다.
유물 교체와 전환 지원, 칩·가산배수·곱배수·재평가로 이어지는 별도 도전 점수도 포함합니다.
팩 연구는 거점의 원정 성장 → 보급 팩 연구에서 확인합니다. 실제로 받는 팩 보상은 한 장입니다.

지역 지도6개·리더 규칙·개별 해금·승인된14명 캐릭터 루트와 기존 B 저장을 유지합니다.
보라·예서의 신규 루트는 보류 상태이며 이전 일반판 play.html과 저장 구분을 유지합니다.

PC·모바일 Chrome과 기존 저장 이관을 확인했습니다. 전체 리더의 난도 균형·모든 히든 분기·Safari 검증은 별도입니다.
